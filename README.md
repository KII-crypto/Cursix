# Cursix 🤖

Cursix is a Python-based desktop voice assistant that I developed as a personal technology project.

The project was created to explore voice interaction, Python programming, speech recognition, text-to-speech, and Windows desktop automation.

## Features

- 🎙️ Voice-based interaction
- ⏰ Tells the current time
- 🌦️ Provides weather information using Open-Meteo
- 🔋 Checks battery status
- 🖥️ Opens Windows applications and folders
- 🎤 Includes microphone and voice testing tools
- 👋 Provides a startup greeting
- ⌨️ Supports press-and-hold Space interaction

## Technologies

- Python
- Vosk
- OpenWakeWord
- SpeechRecognition
- PyAudio
- pyttsx3
- PowerShell
- Open-Meteo API

## Development

Cursix was developed as a learning project while I taught myself Python through practical experimentation, online learning, testing, and debugging.

AI tools were also used during development to assist with coding, debugging, and problem-solving. I tested and adapted the project on my own Windows 11 computer and worked through issues encountered during development.

## Purpose

The purpose of Cursix is to learn how different software components can work together to create a practical desktop assistant, while developing my skills in Python, automation, voice technology, and problem-solving.

## Project Status

Cursix is an ongoing personal project. Features and improvements may be added as I continue learning and developing my programming skills.
